# Aristocrat Video Converter

Конвертер видео и аудио для **Windows 7 / 8 / 10 / 11** и **Linux** с восстановлением и апскейлом старых записей (VHS, Video8, DVD) до 1080p и 4K.

Интерфейс один и тот же на обеих системах: сверху разделы, под ними «Добавить файлы», «Загрузить DVD» и «Конвертировать все в…», в центре список файлов, внизу папка для результатов и кнопка «Конвертировать все».

## Возможности (версия 0.1)

- Конвертация в MP4, HEVC, MKV, MOV, AVI, WMV, WEBM, FLV, MPG, 3GP; извлечение звука в MP3, M4A, WAV, FLAC, OGG, WMA, OPUS.
- Готовые форматы для устройств: iPhone/iPad, Android, Smart TV, YouTube, Telegram/VK, приставки.
- Свои форматы: кодек, разрешение, частота кадров и битрейт.
- Окно «Размер файла»: задаёте размер в мегабайтах, и программа подбирает битрейт.
- Правка: обрезка по времени, кадрирование, поворот и отражение, яркость, контраст, насыщенность, устранение чересстрочности, шумоподавление, водяной знак (текст или картинка), субтитры, выбор звуковой дорожки и громкость.
- Загрузка DVD из папки VIDEO_TS.
- Ускорение видеокартой (NVIDIA NVENC, Intel Quick Sync, AMD AMF), если она поддерживается.
- Объединение всех результатов в один файл.
- Действие после завершения: закрыть программу, спящий режим, выключить компьютер.
- **Апскейл** (этой функции нет в привычных конвертерах):
  - *быстрый*: масштабирование до 1080p или 4K алгоритмом Lanczos;
  - *нейросетевой*: Real-ESRGAN через Vulkan, работает и на встроенной графике Intel;
  - *восстановление VHS*: устранение чересстрочности с сохранением плавности 50 кадров/с, шумоподавление, обрезка дрожащей полосы внизу кадра, исправление пропорций.

  Нейросетевой апскейл обрабатывает видео частями по 10 секунд. Если его остановить, готовые части сохранятся, и кнопка «Продолжить» продолжит работу с того же места.

## Скачать

Готовые сборки появляются во вкладке **Actions** после каждого изменения, а для отмеченных версий (тегов `v*`) — в **Releases**:

- `AristocratVideoConverter-Windows-x64`: папка с программой, распакуйте и запустите `AristocratVideoConverter.exe`;
- `AristocratVideoConverter-x86_64.AppImage`: для Linux, сделайте файл исполняемым и запустите.

FFmpeg и Real-ESRGAN уже лежат в папке `tools` внутри сборки.

## Сборка вручную

Нужны Qt 5.15 (Widgets, Svg), CMake 3.16+ и компилятор C++17.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Положите `ffmpeg` и `ffprobe` в папку `tools` рядом с программой (или установите их в систему). Для нейросетевого апскейла нужна папка `tools/realesrgan` с `realesrgan-ncnn-vulkan` и папкой `models`.

## Ограничения

- **Windows 7**: программа и конвертация работают. Нейросетевой апскейл требует Vulkan, а у многих старых видеокарт под Windows 7 его нет; тогда используйте быстрый апскейл.
- **Windows XP**: в планах отдельная облегчённая сборка (Qt 5.6, без апскейла).
- Разделы «Загрузить», «Запись» и «Передать» пока заглушки.
